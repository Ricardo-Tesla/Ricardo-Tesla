## 🏆 Featured Projects

### 🔹 Projectos *(Private Repo — Startup Product)*
An AI-powered project continuity system that helps founders and knowledge workers get
back into long-running projects after a break. It captures lightweight updates as you
work, then restores full context on return — current state, key decisions, open
questions, blockers, and recommended next actions.

**The challenge:** reconstructing meaningful project context from fragmented, lightweight
updates over time — not just storing a log, but surfacing the decisions and blockers that
actually matter when someone returns weeks later.

**Tech Stack:** TypeScript, Next.js, Tailwind CSS, shadcn/ui, Python, FastAPI, PostgreSQL,
pgvector, SQLAlchemy, Alembic, Clerk, Docker, GitHub Actions, Vercel, Railway

---

### 🔹 [LocalRAG Docs](https://github.com/Ricardo-Tesla/localrag-docs)
A fully local, privacy-first RAG system for technical document Q&A. Upload PDFs, ask
natural-language questions, and get grounded answers with source passages and page
numbers — entirely on-device, zero external API calls.

**The challenge:** keeping every answer verifiable, not just plausible — returning exact
source citations using a multi-stage retrieval pipeline with zero cloud dependency.

**Result:** Retrieval accuracy improved from 1-of-5 to 4-of-5 correct sources on ambiguous
queries using a multi-query retrieval strategy.

**Tech Stack:** Python, FastAPI, ChromaDB, Ollama, Docker

---

### 🔹 [Rica BizTrack](https://github.com/Ricardo-Tesla/rica-biztrack)
An offline desktop business management app for small businesses — inventory, sales,
expenses, and profit/loss reporting, with zero subscription and zero internet dependency.

**The challenge:** guaranteeing financial data integrity with no server to validate
against, while keeping the installer under 6MB for low-connectivity environments.

**Result:** 86 automated tests across 9 business-logic modules, with automated
transaction logging ensuring reporting accuracy.

**Tech Stack:** Rust, Tauri, React, SQLite

---

### 🔹 [EaseBus — Bus Reservation System](https://github.com/Ricardo-Tesla/Bus-Booking-and-Reservation-web-app)
A bus reservation system built for Kenya's leading bus charter services — seat selection,
route scheduling, dynamic pricing, and ticket verification.

**The challenge:** keeping real-time seat availability accurate across VIP and regular
pricing tiers while preventing double-booking on concurrent reservations.

**Tech Stack:** Node.js, Express.js, Express Handlebars, JavaScript, Bootstrap 5

---

### 🔹 [Assign Proj](https://github.com/Ricardo-Tesla/AssignProj)
A project management platform for academic group work — students collaborate on tasks
and submissions while lecturers track each group's individual contributions.

**The challenge:** designing role-based visibility into individual contributions within a
group, without disrupting students' own collaborative workflow.

**Tech Stack:** JavaScript, HTML, CSS
